# EasyFlow 页面陪办助手

EasyFlow 是一个运行在**用户主动打开的真实第三方网页**上的聊天式浏览器指引扩展。用户说一句话，它会判断：

- 直接回答当前页面上能查到的信息；
- 追问缺失的目标；
- 给出一个可执行的下一步，并允许“指给我看”；
- 或者坦诚说明当前页面没有依据。

> 0.2.0 已将浅紫侧栏、当前步骤卡片、大字模式和设置弹窗集成到真实扩展。默认使用本地规则；在设置中开启“在线智能”后，才发送脱敏页面摘要到服务器的 HTTPS 代理。模型密钥由服务器管理，安装扩展不需要本机代理。语音输入和朗读保留原实现，设备支持情况仍需在用户电脑上验收。

> 0.2.1 修复切页后的读取状态与恢复流程，新增可选的“切页自动读取”。它默认不会申请跨站读取权限；需要在设置中点击开启，并在浏览器弹窗中允许。不开启时，到未授权页面后点击工具栏中的 EasyFlow 图标，也能按单页授权方式使用。

## 当前进度

- 已在真实网页演示：政务指南问答与原文定位；Cal.com 日期、动态可用时段的逐步指引及预约成功页识别；普通/长者关怀模式。
- 0.2.0：真实侧栏 UI、HTTPS 在线模型协议及精确原文引用校验已集成；固定关键词的中文排序，避免不同浏览器语言出现不同匹配结果。
- 0.2.1：区分“新页面需要授权”和受保护页面；重新点击工具栏图标后可恢复读取，并处理页面切换期间的旧请求结果。提供可开启、可撤销的跨页读取授权。
- 待用户设备验收：语音输入、朗读音效和此前报告的特定网站高亮闪烁。历史实测中，浏览器语音服务网络及中文本机资源安装曾失败。
- `codearts_proof/` 保存各轮实现与测试说明。自动测试、真实浏览器验收和待验项目在这些记录中分别标注。

## 技术栈

- Manifest V3 + TypeScript + React 18
- esbuild 三入口：后台 ESM、content IIFE、侧边栏 ESM + CSS
- 本地规则对话引擎 + 可替换 `DialogueEngine` 接口
- 无 UI 框架、无路由库、无远程 SDK

## 安装与构建

要求 Node.js 20+、npm 10+。

```bash
npm install
```

依赖已在本地且网络受限时：

```bash
npm install --offline
```

构建：

```bash
npm run build
```

构建链：`tsc --noEmit` → 清空 `dist/` → 生成图标 → esbuild 三入口 → 复制清单/HTML → 清单与门禁校验。

产物位置：项目根目录的 `dist/`。安装时选择包含 `manifest.json` 的文件夹。

其他命令：

```bash
npm run typecheck
npm run selftest
npm run verify
```

## 在 Chrome 中加载

1. 打开 `chrome://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择 `dist` 目录。
5. 建议把 EasyFlow 固定到工具栏。

### 更新到 0.2.1

1. 下载 `easyflow-page-guide-0.2.1.zip` 并解压到原来的扩展目录。
2. 在 `chrome://extensions` 或 `edge://extensions` 找到 EasyFlow，点击“重新加载”，确认版本为 **0.2.1**。
3. 刷新目标网页，重新点击工具栏中的 EasyFlow 图标打开侧栏。
4. 若希望切换普通网站后自动读取，在侧栏“使用帮助与设置”中开启“切页自动读取”，并在浏览器出现的权限弹窗中选择允许。

如果解压到新目录并重新加载为另一个扩展，请先停用旧版本。安装包不会自动更新已经加载的扩展。

## 使用方式

### 1. 打开与自动读取

打开目标网页后点击 EasyFlow 图标。侧边栏会先显示欢迎语和输入框，再自动读取当前页；不需要先点任何工作流按钮。

页面状态会区分读取中、成功和具体阻碍：

- 正在读取当前页面…
- 已看到 `<域名>` 的页面
- 新页面需要授权（可开启“切页自动读取”，或点击工具栏图标只读取这一页）
- 此页面受浏览器保护，无法读取
- 其他读取失败的具体原因与重试入口
- 页面已变化，正在核对

未授权时，仅点击刷新按钮不能代替浏览器授权。请点击工具栏的 EasyFlow 图标，或按设置中的“切页自动读取”流程授权。普通加载失败可等网页加载完成后重新读取。

### 2. 直接回答

主验收页可以输入：

```text
高龄津贴谁能申请
```

预期：

- 1—3 句可理解回答；
- 回答下方有可折叠“网页依据”；
- 展开后显示原文片段和“在网页中查看”；
- “在网页中查看”滚动并高亮真实文字，约 4 秒后移除。

继续追问：

```text
在哪里线下办理
那需要带什么
```

系统会沿用上一轮的对象继续回答，不要求用户重新解释目标。

如果当前页没有信息，会明确说“当前页面没有找到这项信息”，不会补写金额、地址、电话或办理结果。

### 3. 逐步陪办

建行网点查询页可以输入：

```text
第一次办借记卡，先找营业网点
```

预期：

- 只给一个下一步，例如“先选择所在城市或地区”；
- 消息内嵌“指给我看”；
- 点击后只滚动、高亮真实控件，不点击、不聚焦、不填写；
- 用户自行完成后可以点“我已完成”，或等待 DOM 变化触发复审；
- “我找不到”会重新定位控件；
- “我点错了”会基于当前页重新规划；
- “换一个任务”会结束旧计划并重新询问目标。

步骤完成判定只认：

- 页面文本/控件变化；
- 页面地址变化；
- 用户明确点“我已完成”。

不会用定时器假装完成。无法确认时会说：“我还不能确认这一步是否完成”。

### 4. 网页切换

切换标签页、刷新或导航后：

- 聊天记录保留；
- 旧引用标记为已失效；
- 当前步骤转为待复核；
- 在具备当前页面权限后重新读取并核对，不把旧页面结果当作新页面依据。

**开启跨页读取：**进入侧栏设置 → 开启“切页自动读取” → 在浏览器权限弹窗中允许访问普通 HTTP/HTTPS 网站。授权成功后，侧栏打开时会跟随当前标签页读取；可在同一个开关关闭并撤销这项可选权限。“切页自动读取”和“在线智能”是两个独立开关，前者不会自动开启模型请求。

**保留单页授权：**不需要跨站权限时保持关闭。切换到尚未授权的标签页或跨站跳转后，点击浏览器工具栏里的 EasyFlow 图标，扩展会重新取得这一页的临时授权并读取。

**受保护页面：**`chrome://`、`edge://` 等浏览器内部页面、扩展商店及部分浏览器保护页面不能注入读取脚本。即使开启跨页读取，也不能绕过这些限制；请切换到普通网页使用。

### 5. 建行申请页只读边界

可以问：

```text
这个页面要填什么
指给我看手机号那一栏
```

扩展只会引用字段标签与页面解释文字，并高亮标签；不会读取 `input.value`。

会拒绝：

```text
帮我填身份证号
帮我勾选协议并提交
验证码是多少
```

这些操作需要用户本人完成，扩展不代填、不代勾选、不代提交、不索取验证码。

## DeepSeek 在线模式

- 默认使用本地规则。点击顶部“本地规则”或设置按钮，在弹窗中开启“在线智能”；服务不可用或输出无依据时自动回退。
- 生产接口为 `https://124.221.252.80:8090/easyflow/page-guide-api`，地址定义在 `src/shared/model/config.ts`。浏览器不含模型密钥、不直连模型厂商。
- `GET /health` 检查代理状态；`POST /v1/dialogue` 返回 `result.kind`、`result.answer`、`result.evidence`。每条依据必须包含页面段落的 `segmentId` 和连续原文 `quote`。
- 扩展同时核对发送摘要和原始页面元素，拒绝缺失、错配及脱敏前后不一致的引用。步骤规划、控件定位和高亮继续由本地代码执行。
- 健康检查超时 5 秒，模型请求超时 17 秒。服务器保留调用限额，达到限额时本地规则仍可使用。

安装与开启：

1. 下载线上 0.2.1 ZIP 并解压，或执行 `npm ci && npm run build`。
2. 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式，加载解压目录；更新旧版时需重新加载扩展。
3. 刷新目标网页，点击工具栏的 EasyFlow 图标。
4. 在“使用帮助与设置”中开启“在线智能”，再针对当前页面提问。连接状态只表示代理可达，单次请求失败会提示并回退。

- `scripts/model-proxy.mjs` 与 `.env.example` 仅保留作旧版本地开发参考，0.2.x 生产扩展不会连接此本机代理。它的旧回复协议不能直接替换生产接口。
- 不读取或发送 `input.value` 与完整页面 HTML；出站前识别并替换证件号、手机号、银行卡号、邮箱等明显敏感值。网页可见文字仍可能含姓名等无法可靠自动识别的信息，开启在线模式前应确认页面适合发送摘要。
- 语音输入已实现浏览器服务、本机能力检测及授权页，但当前实测设备上尚不可用；文字输入始终可用。朗读使用浏览器语音合成，真实设备效果仍待验收。

## 权限与隐私

清单权限仍为四项：

- `activeTab`
- `scripting`
- `sidePanel`
- `storage`

基础 `host_permissions` 仍仅包含 `https://124.221.252.80/*` 服务器。模型请求固定使用上述 8090 HTTPS 接口。

0.2.1 新增 `optional_host_permissions`：`http://*/*` 和 `https://*/*`。安装时不会因此自动获得所有普通网站的访问权；只有用户点击“切页自动读取”并在浏览器中允许后才启用。这项权限允许扩展访问普通 HTTP/HTTPS 网站，本扩展仅在打开侧栏时读取当前页面。关闭开关会请求撤销这些可选权限，状态以浏览器实际结果为准；拒绝授权仍可使用工具栏的单页授权方式。

未申请：

- `<all_urls>`
- 静态 `content_scripts`
- `tabs`
- 麦克风相关权限

只读约束：

- 采集只调用只读 DOM API；
- 不读取输入框/文本域/下拉框的 `value` 或选中值；
- 只保留按钮 `button/submit/reset` 的 `value` 作为按钮文字兜底；
- 不修改原网页节点文本、属性、结构；
- 唯一页面写入是临时高亮宿主，约 4 秒后移除；
- 不点击、不聚焦、不勾选、不填写、不提交、不处理验证码。

会话与存储：

- 页面正文、语义段、引用、聊天、步骤只存在侧边栏内存；
- `chrome.storage.local` 保存用户目标 `easyflow.goal`（≤200 字）、界面模式和在线模式开关；
- 关闭侧边栏即结束会话，重开重新读取当前页。

## 已知限制

- 规则模式不保证语义理解；在线模式依赖服务器代理、DeepSeek 可用性与页面采集质量。
- 只读取主文档，不进入 iframe；地图/内嵌框架内的结果读不到。
- 网页依据按单条引用定位；标题+正文批量高亮的消息字段已预留，但本轮 UI 未启用。
- 跨域下一步只给文字说明，不自动导航、不新开标签。
- 登录、实名、验证码、提交、支付等步骤停止推进，需要用户本人完成。
- 懒加载、分页、站点改版可能导致控件找不到；会说明真实原因，不假装成功。
- “切页自动读取”关闭时，`activeTab` 临时权限不会自动跟随所有新标签或跨源导航；需要重新点击工具栏扩展图标。开启并授权后，普通网页可跨页读取，但浏览器内部页和扩展商店等仍受限制。
